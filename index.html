Ini beberapa Project yang pernah saya lakukan

Membangun Server Website Mandiri
Menggunakan VirtualBox, Ubuntu Server, BarePod, dan Cloudflare Tunnel

Proyek ini bertujuan untuk membangun dan mempublikasikan sebuah website portfolio secara mandiri (self-hosted) dari komputer lokal ke internet publik tanpa memerlukan VPS berbayar atau pengaturan router yang rumit.

Arsitektur & Komponen yang Digunakan:

VirtualBox (Hypervisor Tipe 2):
Digunakan untuk menjalankan sistem operasi server secara virtual di atas laptop dengan konfigurasi jaringan ganda (NAT untuk akses internet VM dan Host-Only untuk manajemen lokal).

Ubuntu Server 22.04 LTS:
Berfungsi sebagai sistem operasi server utama yang handal dan ringan.

BarePod Panel:
Panel manajemen hosting open-source berbasis web untuk mengelola file website, layanan web server, dan kontainer dengan mudah.

Sumopod & Cloudflare:
Pengelolaan domain pribadi (.my.id) yang diintegrasikan dengan Cloudflare DNS.

Cloudflare Tunnel:
Teknologi secure tunneling untuk menghubungkan server lokal di dalam jaringan privat langsung ke internet publik secara aman dengan enkripsi SSL otomatis (HTTPS).

Hasil Akhir:
Website portfolio berhasil di-deploy secara lokal di dalam server virtual dan dapat diakses secara global oleh publik melalui internet menggunakan domain sendiri dengan aman dan lancar.
